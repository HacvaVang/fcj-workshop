### Results achieved in Week 1:

* **Onboarding & Team Connection:**
  * Connected with the FCAJ group, understood the rules.
  * Set up a shared working environment with Git and AWS Free Tier account.

* **Basic Understanding of AWS:**
  * Mastered AWS concepts and core service groups such as Compute, Storage, Networking, and Database.
  * Practiced creating EC2, configuring SSH, attaching EBS volumes, and understanding resource initialization workflows.
  * Experienced AWS Lambda, Lambda Function URL, and Amazon Bedrock to get familiar with serverless and Generative AI.

* **Account Management & Tools:**
  * Installed AWS CLI, configured Access Key/Secret Key, and default Region.
  * Used AWS CLI to inspect account details, list Regions, view EC2 services, create key pairs, and manage resources.
  * Combined Management Console and CLI within a single unified workflow.

* **System Design:**
  * Designed simple VPC and Multi-AZ VPC diagrams on draw.io to standardize AWS architecture thinking.
  * Gained the ability to model network environments, route tables, and gateways in cloud architecture.
